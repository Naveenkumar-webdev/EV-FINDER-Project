# EV Finder

A full-stack web application for discovering EV charging stations and booking available slots.

## Features
- District-based station search and filtering
- Admin panel for adding, updating, and deleting station records
- Secure forgot-password flow with OTP verification (via MSG91)
- Responsive frontend built with HTML5, CSS3, and JavaScript

## Tech Stack
- **Backend:** Java 21, Spring Boot 3.5.3
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript
- **SMS/OTP:** MSG91 (DLT/TRAI-registered sender)
